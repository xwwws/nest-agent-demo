# 目标八 · 全局守卫 + 公开路由放行

> 本章要做什么：全局守卫落地后，登录/注册等公开接口也会被拦。本章用 `@Public` / `@PublicWhiteList` 装饰器 + `Reflector` 读元数据，实现在全局守卫下放行公开路由。

> 承接目标七 7.7：`APP_GUARD` 全局守卫落地后，登录/注册也会被拦，本块用装饰器 + `Reflector` 放行公开接口。

## 8.1 问题背景

全局守卫让「所有路由默认鉴权」，但登录/注册本就该公开。Nest 的解法：**用 `SetMetadata` 给路由打标记 → 守卫里用 `Reflector` 读标记决定放行**。

## 8.2 SetMetadata + @Public 装饰器

`@Public()` 本质是给「处理器/类」挂一段元数据：

```ts
export const IS_PUBLIC_KEY = 'isPublic';                      // 元数据 key（抽常量防拼写错误）
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true); // 打标记：isPublic = true
```

- `SetMetadata(key, value)`：来自 `@nestjs/common`，把 `{ [key]: value }` 写进路由的元数据。
- `@Public()` 是「返回装饰器的函数」，符合 Nest 装饰器的工厂惯例。

## 8.3 Reflector 读取元数据

`Reflector` 是 Nest 读取元数据的服务（`@nestjs/core`），守卫注入后即可查询：

```ts
const isPublic = reflector.getAllAndOverride(IS_PUBLIC_KEY, [handler, class]);
```

| 方法 | 区别 |
| --- | --- |
| `getAllAndOverride(key, [handler, class])` | 方法级优先、类级兜底：方法有值用方法，否则用类 |
| `getAllAndMerge(key, [handler, class])` | 方法级 + 类级合并成数组 |

> 用 `getAllAndOverride`：既能给单个路由标 `@Public()`，也能给整个 controller 标。

## 8.4 JwtGuard 重写 canActivate

完整版 `JwtGuard` 注入 `Reflector`，在 `canActivate` 里先判公开、再走 passport：

```ts
canActivate(context) {
  const isPublic = reflector.getAllAndOverride(IS_PUBLIC_KEY, [handler, class]);
  if (isPublic) return true;         // 公开 → 直接放行，不走验签
  return super.canActivate(context);  // 非公开 → 交给父类 AuthGuard('jwt') 验签
}
```

- `super.canActivate(context)`：调用父类 `AuthGuard('jwt')`，触发 passport 验签（见目标七）。
- 公开路由**不会**走到 passport，所以 `req.user` 为空（见目标九 9.3）。

## 8.5 @PublicWhiteList / @PublicApi（路径白名单）

除「整条公开」外，还支持「按路径白名单」：

```ts
export const PUBLIC_WHITE_LIST_KEY = 'publicWhiteList';
export const PublicWhiteList = (paths) => SetMetadata(PUBLIC_WHITE_LIST_KEY, paths);
export const PublicApi = (paths?) => (paths ? 组合(白名单 + Public) : Public());
```

守卫里先匹配路径再决定：

```ts
if (whiteList?.some((p) => matchPath(request.path, p))) return true; // 命中白名单放行
```

`matchPath` 支持通配符：含 `**` 用前缀匹配（`startsWith`），否则全等比较。

| 装饰器 | 作用 |
| --- | --- |
| `@Public()` | 整条路由公开（标记 `isPublic`） |
| `@PublicWhiteList(['/a/b'])` | 指定路径公开（标记白名单数组） |
| `@PublicApi(paths?)` | 组合：带参 = 白名单 + Public，不带参 = 仅 Public |

> 本项目登录/注册用 `@PublicApi()`（不带参，等价 `@Public()`）。

## 8.6 易错点

1. **元数据 key 要复用常量**：`SetMetadata` 的 key 别到处写裸字符串，抽 `IS_PUBLIC_KEY` 常量，否则 key 拼错难排查。
2. **`getAllAndOverride` 顺序**：`[handler, class]` 方法级在前，方法有值会覆盖类级，符合直觉。
3. **公开路由里别读 `req.user`**：放行时未走 passport，`req.user` 是 undefined。
4. **装饰器调用要带括号**：`@Public()` 是返回装饰器的函数，漏写 `()` 不生效。
5. **白名单匹配的是 `request.path`**：不含 query string，注意是否要拼路由前缀。
