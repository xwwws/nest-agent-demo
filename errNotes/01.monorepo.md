# 目标一 · Monorepo

> 本章要做什么：理解「单仓库（Monorepo）」是什么、相比多仓库（Polyrepo）有什么优势；掌握本项目用 `pnpm workspace` + `Turborepo` 组织多个包的方式，并能熟练使用常用命令、避开多包管理的坑。

## 1.1 概述

**Monorepo（单仓库）**：把多个相互关联的项目/包放在同一个 Git 仓库里统一管理。

| 对比项 | Monorepo | Polyrepo |
| --- | --- | --- |
| 代码位置 | 一个仓库多个包 | 一个仓库一个项目 |
| 依赖共享 | 本地包直接引用（`workspace:*`） | 需发 npm 包或拷贝代码 |
| 版本一致性 | 统一 lockfile | 各仓库独立，易漂移 |
| 典型工具 | pnpm workspace / Turborepo / nx | 无 |

**本项目选型**：`pnpm`（包管理 + workspace）+ `Turborepo`（任务编排）。

## 1.2 本项目结构

```
nest-demo/
├── apps/                 # 可独立部署的应用
│   ├── api/              # NestJS 后端
│   └── web/              # Next.js 前端
├── packages/types/       # 共享 TS 类型包（@agent-workspace/types）
├── pnpm-workspace.yaml   # 声明 workspace 范围
├── turbo.json            # 任务编排配置
└── pnpm-lock.yaml        # 统一锁文件
```

约定：`apps/` 放可独立运行的应用，`packages/` 放被复用的库。共享包用作用域命名 `@xxx/yyy`，避免与 npm 公共包冲突。

## 1.3 pnpm workspace

- **声明范围**：`pnpm-workspace.yaml` 里写 `packages: ["apps/*", "packages/*"]`，子目录有 `package.json` 即被识别为 workspace 包。
- **本地引用**：`web` 引用共享包写 `"@agent-workspace/types": "workspace:*"`，安装时 pnpm **软链接**到本地 `packages/types`，改了类型立即生效、无需发版。
- **统一管理**：根 `pnpm-lock.yaml` 锁全仓版本；公共工具（turbo）放根 `devDependencies`；`packageManager` 字段固定 `pnpm@11.23.0`。

## 1.4 Turborepo 任务编排

负责「在多个包里并行/按依赖顺序执行脚本」并做缓存。根 `package.json` 的 `dev/build/lint` 都是 `turbo xxx` 聚合。

`turbo.json` 关键字段：

| 字段 | 作用 |
| --- | --- |
| `dependsOn: ["^build"]` | `^` = 依赖的包；先构建依赖包，再构建自己 |
| `outputs` | 声明产物路径，用于缓存判断（产物没变就跳过） |
| `cache: false` | 关闭缓存（开发脚本通常关掉） |
| `persistent: true` | 常驻任务（`next dev` / `nest start --watch`），turbo 不等待其结束 |

依赖关系由各包 `dependencies`（含 `workspace:*`）自动推断，无需手动声明。

## 1.5 常用命令

| 命令 | 作用 |
| --- | --- |
| `pnpm install` | 安装全仓依赖（根目录） |
| `pnpm dev` / `pnpm build` / `pnpm lint` | 聚合执行所有包对应脚本 |
| `pnpm --filter api dev` | 只启动 `api` 包 |
| `pnpm --filter api add xxx` | 给 `api` 包添加依赖 |

> `--filter` 按包名/路径定位子包执行，日常开发单包时最常用。

## 1.6 易错点

1. 新建 workspace 包后要重新 `pnpm install` 才生成软链接。
2. 共享包引用写全名 `@agent-workspace/types`，别写 `types`。
3. `workspace:*` 只在 monorepo 内有效，未来发 npm 需改真实版本号。
4. `persistent: true` 必须给 dev 类常驻脚本，否则 `turbo dev` 会提前结束。
5. 全仓只用 pnpm，混用 npm/yarn 会导致 lockfile 不一致。
